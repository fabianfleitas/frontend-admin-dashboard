# Admin Dashboard Functional Specifications

# Documento 13 --- Design System & Component Library

## Objetivo

Definir los componentes reutilizables del dashboard.

## Componentes base

Layout: - Sidebar - Header - Breadcrumb

Datos: - DataTable - Pagination - SearchBar - Filters

Feedback: - Toast - EmptyState - Skeleton - Alert

Visualización: - MetricCard - StatusBadge - Timeline - Drawer - Modal

## Reglas

-   Un componente = una responsabilidad.
-   Props tipadas.
-   Accesibilidad.
-   Consistencia visual.
-   Reutilización antes que duplicación.
