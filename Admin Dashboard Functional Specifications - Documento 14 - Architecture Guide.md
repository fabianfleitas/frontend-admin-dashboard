## Principios

-   Feature First
-   Componentes reutilizables
-   Servicios desacoplados
-   TanStack Query para estado servidor
-   Zustand para estado UI
-   Integración exclusiva mediante API REST

## Resultado esperado

Una aplicación mantenible, escalable y alineada con la arquitectura del
backend y los objetivos de la tesis.
